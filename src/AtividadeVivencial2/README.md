# Vivencial 2

Nomes: Bruno Silveira Gerling, Lucas Rafael Locatelli, Mariana Machado Sales e Matheus Marcolin Trindade

Este projeto exibe um cenário 2D com múltiplas camadas (parallax) e um personagem controlável pelo teclado.

## O que o código faz
- Mostra um fundo com várias camadas que se movem em velocidades diferentes, criando efeito de profundidade.
- Permite mover o personagem principal para os lados usando as setas do teclado.
- O fundo se repete horizontalmente conforme o personagem se move.

## Como usar
1. Compile o projeto (por exemplo, usando CMake ou o comando de sua preferência).
2. Execute o arquivo `vivencial2.exe` na pasta `build`.
3. Use as setas do teclado ⬅️➡️ para mover o personagem e ver o efeito parallax.
