# DesafioM4 - Instanciando objetos texturizados

## Funcionalidades

- Renderização de múltiplos sprites (retângulos) com diferentes texturas.
- Transformações individuais: posição, escala (permitindo retângulos de qualquer proporção) e rotação.
- Projeção ortográfica para facilitar o posicionamento em coordenadas de pixel.

## Como usar
1. Compile o projeto (por exemplo, usando CMake ou o comando de sua preferência).
2. Execute o arquivo `DesafioM4.exe` na pasta `build`.
